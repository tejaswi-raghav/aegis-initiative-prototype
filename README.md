# The Aegis Initiative

An interactive prototype for a personalized cinematic-universe identity experience.

The visitor enters their name, chooses a division, and uploads a portrait. The portrait stays in the browser and is used to build a scroll-driven personnel dossier, mission briefing, and downloadable appointment certificate.

## Run locally

Serve this directory with any static web server. For example:

```sh
npx serve .
```

No build step or environment variables are required.

## Privacy

Uploaded portraits are represented with an in-browser object URL. They are not transmitted or persisted by this prototype.
